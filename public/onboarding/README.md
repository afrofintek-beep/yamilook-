# Regional onboarding photographs

Approved AI-generated concept photographs for Arabic (ar), Amharic (am), and isiZulu (zu), approved on 2026-11-05. Nine individual scenes per language: identity, birthday, welcome, avatar, bio, chat, calls, groups, stories. Extracted from the approved nine-panel sheets, without changing their content, and encoded as WebP. Fictional people; these are illustrative images, not documentary photographs.

Arabic scenes draw on Morocco, Mauritania, Egypt, Tunisia and Sudan. Amharic scenes use Ethiopian settings. isiZulu scenes use KwaZulu-Natal settings. Existing square step frames and responsive tour frames are retained. The tour uses its existing manual navigation; welcome-page carousel timing is unchanged.
