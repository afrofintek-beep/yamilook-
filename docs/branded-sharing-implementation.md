# Branded sharing

Authors can choose **Partilhar com a marca Yamilook** from the publication sharing dialog. Photos and video frames receive the official logo and the server-verified author's display name and handle, in a separate header that does not cover the source. Text exports paginate into 1080 × 1350 JPEG cards without truncation. Every output is previewed before a separate native-share tap; a download is available on unsupported browsers. The original-file workflow remains available below.

The `owned-post-media` branding mode validates Auth, the active session, ownership, RLS and moderation before returning text and attribution. The browser checks again after conversion. Export never changes the post audience. The recipient receives a copy and can save or forward it. This does not make pre-existing public storage URLs private.

Video uses pinned Mediabunny 1.65.1 and WebCodecs, loaded only when exporting. AVC/AAC MP4 is preferred; compatible audio packets are copied, otherwise audio is transcoded. WebM/Opus is offered explicitly when MP4 encoding is unavailable. No microphone capture or third-party media upload occurs. A conversion is rejected if its primary audio track is dropped. The completed file is reparsed to validate video, audio and duration before showing the preview.

Limits: 100 MiB source/output, 10-minute video duration, 1280px maximum source-video edge, 30fps output, 24-megapixel photo input, 1600px photo output edge, 30 text cards. Source video resolution may be reduced; this is not lossless video export. Animated GIFs are directed to the original-file workflow rather than flattened. HEIC and other image decoding depend on browser support. A browser without compatible decoders/encoders offers the original-file workflow rather than silently exporting without sound. Keep the page open; cancellation/unmount stops conversion and object URLs are released.

Validation: owner/auth/session/moderation and media-stream Node tests; component tests for preview, fresh user activation, downloading, pagination, cancellation and changed-content rejection; video-unit tests prevent silently discarded audio. CI additionally generates a 3-second AVC/AAC fixture, converts it in Chromium, downloads the actual result, uses ffprobe to inspect tracks/duration and ffmpeg to check audible decoded samples (and identical AAC samples when copied), and retains video/frame artifacts. TypeScript and production build are included in the sharing workflow. Physical iPhone/Android application share sheets require device validation; CI does not claim to simulate those apps.
