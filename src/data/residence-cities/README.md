# Residence suggestions

Source: GeoNames cities500 via geonamescache 3.0.2 (PyPI wheel), retrieved 2026-11-06.
https://download.geonames.org/export/dump/readme.txt
https://pypi.org/project/geonamescache/3.0.2/

GeoNames data: https://www.geonames.org/ — CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/

The seven region files retain only country codes and place names; identical names
within a country are deduplicated because profiles currently store a city string,
not a municipality ID. Capital names from country records are included. Historical
country codes AN and CS are excluded. The catalog contains 249 ISO countries and
territories plus XK (Kosovo), matching the source's current-country coverage.
Existing curated African city names and neighborhood suggestions remain available.
Country display names use bundled Intl/CLDR labels for the ten supported languages.
City names retain the source spelling; they are not machine-translated.

This is a suggestions catalog, not an exhaustive list or an administrative
boundary authority. Users can enter a missing locality directly. All datasets are
served by the application; searching does not send address data to GeoNames.
